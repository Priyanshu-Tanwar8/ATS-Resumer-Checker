# 📄 ATS Resume Tracking System

An AI-powered ATS Resume Tracking System that analyzes resumes against job descriptions and provides actionable insights to help candidates improve their resumes and skills.

## 📸 Application Preview

### 🖥️ User Interface

The application provides a simple interface where users can enter a job description and upload their resume in PDF format.

## 🤖 AI-Powered Resume Analysis

### 💡 Skill Improvement Advice

The system analyzes the uploaded resume and provides personalized recommendations for improving technical skills.

<img width="1003" height="708" alt="Screenshot 2026-08-14 101817" src="https://github.com/user-attachments/assets/d49fecf6-30c4-4821-9ed3-224e9a49427f" />

The analysis can identify areas such as:

* Data Engineering
* Backend Development
* Data Analytics
* Advanced SQL
* Cloud Platforms
* DevOps & Containerization
* Data Warehousing
* Vector Databases
* Software Testing

---

## 🎯 Personalized Recommendations

The system can provide detailed recommendations based on the candidate's existing skills and career direction.

For example, it can recommend technologies such as:

* Apache Airflow
* PySpark / Apache Spark
* dbt
* Snowflake
* AWS
* FastAPI
* PostgreSQL
* Docker
* GitHub Actions
* Tableau / Power BI

## 🚀 Project Suggestions

The application can also identify gaps in a candidate's profile and suggest practical projects that can help strengthen their resume.

For example, it can recommend building a **cloud-native data pipeline** using technologies such as Python, Airflow, Docker, AWS S3, Snowflake, dbt, and Power BI.

## 📊 Percentage Match

The **Percentage Match** feature compares the uploaded resume with the provided job description and helps the candidate understand how closely their profile matches the target role.

## 🔄 Application Workflow

```text
        Job Description
              │
              ▼
        Upload Resume
              │
              ▼
       PDF Processing
              │
              ▼
       AI Resume Analysis
              │
       ┌──────┼──────┐
       ▼      ▼      ▼
    Resume  Skills  Percentage
    Info    Advice    Match
       │      │        │
       └──────┼────────┘
              ▼
       Personalized
       Recommendations
```
