# ATS Resume Checker

An AI-powered ATS Resume Checker built using Streamlit and Google Gemini API to analyze resumes against job descriptions and provide ATS match scores, missing keyword analysis, and personalized improvement suggestions.

## Features

* ATS Resume Score Analysis
* Missing Keyword Detection
* AI-Based Resume Feedback
* Resume and Job Description Comparison
* PDF Resume Upload Support
* Skill Improvement Suggestions

## Technologies Used

* Python
* Streamlit
* Google Gemini API
* PDF2Image
* Pillow
* Python Dotenv

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
